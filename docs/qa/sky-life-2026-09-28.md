# 云端访客实现与验证

飞毯路线和出场时间已在后续调整为左下云层停留问候，最新规则见 [飞毯来访记录](carpet-visit-2026-09-28.md)。下文保留初版验收记录。

保留主场景构图，新增飞船巡航、机甲采集、悬浮巡检员、魔毯及低频流星。四个角色素材使用内置 ImageGen，详见 [素材和完整提示词](sky-life-assets.md)。

- 活跃场景时间约 168 秒一轮，最多同时出现两位访客。飞船约第 2 秒开始进入，机甲约第 13 秒、巡检员约第 46 秒，魔毯较晚出现。面板、页面隐藏与全局动态暂停均冻结计时；重新打开网页重新开始氛围周期，不写入家庭进度。
- 采集与巡检使用停留阶段、柔和光效与短标签。飞船和魔毯在远景天空中运动，巡检员在平台外侧巡查。小镇 UI 始终在访客之上；全部访客层 `pointer-events:none`。
- 独立素材失败仅隐藏该访客，不阻塞进入小镇。装饰层不进入辅助技术阅读顺序，不触发公告、任务、扣币或设备状态修改。
- 22 项前端测试通过，包含全周期数量上限、作业停留、暂停冻结、长帧不追赶及循环边界。普通构建与 Python 家庭版构建均通过。
- 浏览器实际查看飞船、机甲、巡检员、魔毯、流星。根据主场景右侧入口和底部工具栏的位置，收紧机甲停留点、向左移动第二处巡检点。
- 实际主场景打开今日安排后，飞船坐标保持 `64.6399%, 7.07065%` 不变；关闭面板后恢复。平台点击后主角进入 `walk` 状态，点击小乖进入 `hop` 并出现“喵～陪我玩一会儿。”，无弹窗，余额保持 0。

画面核验入口 `docs/qa/sky-life.html` 由 Vite 提供，仅用于选择氛围时间点，不读取或修改玩家数据；其画面共用生产组件 `SkyVisitors`。实际体验仍用 Python 服务 `http://127.0.0.1:4180/`。未修改后端或邮件机制。
