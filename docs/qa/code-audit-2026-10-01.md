## 已复现问题与进度

| 问题 | 根因和影响 | 处理 |
| --- | --- | --- |
| 旧同步结果覆盖新进度 | 轮询请求先开始、保存请求先结束时，旧 revision 仍会覆盖余额与任务 | 根据 revision 单调合并；相同版本保留对象，避免每 5 秒无效重渲染；新增异步乱序测试通过 |
| 连续重试缺少请求锁 | React 状态刷新前可以再次调用保存 | 增加同步 ref 锁，保留 operationId 幂等机制 |
| 导入错误类型的字段 | 字符串 false 被转换为已领取；非法建设时间能转为 NaN | 布尔和有限数字严格校验，失败不修改原存档；接口临时数据库测试通过 |
| 单机损坏存档进入渲染 | 日期、开始时间、重复任务与建设位置未校验 | 补充读取校验，保留原损坏文件并展示恢复提示；异常日期、备注、分类、回顾和重复记录测试通过 |
| 周报重试与自动发送竞争 | 检查状态后无条件重置为 pending，可覆盖发送中的认领 | 条件更新核对读取到的状态；并发交错测试通过，禁止重复入队 |
| IPv6 本机访问被拒绝 | 用冒号分割 Host，把 IPv6 地址截断 | 使用 URL hostname 解析；本机地址测试通过 |
| 温室人物比例规则失效 | 公共样式后加载，覆盖第二幕 8.5% 宽度 | 在统一比例文件里按场景设置变量；1011.95px 场景实测第一幕 109.29px、第二幕 86.01px，比例正确 |
| 第一幕采集请求取消后序号脱节 | 本地先累计，取消后没有回到服务器序号，后续请求一直被判跳号 | 恢复动态时与已保存序号对齐；取消后下一次掉落可继续、成功存档不回退、他处更新向前对齐测试通过 |
| 温室光影没有随动态开关暂停 | `.life-paused *` 仅暂停子节点，遗漏带动画的节点本身 | 浏览器复现关闭动态后光影仍 running，补全自身节点的暂停选择器；复核关闭为 paused、开启为 running |
