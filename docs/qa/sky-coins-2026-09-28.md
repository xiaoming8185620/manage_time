# 云晶采集掉币与拾取

每次采集结束独立判定 30% 概率，命中掉落 1 星球币；不命中也保存采集序号。落点为平台内三处空地，复用 `miaomiao-coin.png`，显示柔和微光与下落动画，44×44 像素触控范围。同一落点多枚金币堆叠，逐枚拾取，无倒计时。

点击落地金币后使用主角现有迈步动作前往，到达回调才发起领取；改道、打开面板、页面隐藏会取消未完成的走动与拾取。暂停动态可静态移动并领取。未领取金币保留在存档里，不因刷新消失。

Python 家庭版使用 `secrets.randbelow(100) < 30`，不信任客户端的随机值或奖励金额。采集序号防止重新抽取已结算的采集，SQLite 原有事务、操作去重和 revision 校验处理重试及多设备竞争。领取事件写入每日手记。导入存档重新核算任务收入与拾取收入、建设和照料消费；旧存档没有掉落字段时兼容读取。

验证：31 项前端测试、39 项 Python 测试通过；标准前端与家庭版构建通过。覆盖 29/30 边界、100 个等距样本的 30 次命中、未拾取不加币、重复领取、重复抽取、进程重开后状态保留、revision 冲突、每日事件、导出导入和无效存档。

浏览器使用 `docs/qa/sky-coins.html` 的独立临时状态，显式固定测试概率，不读写孩子存档。观察自然采集结束后出现一枚金币；点击后主角呈 walk 状态而余额仍为 0，到达后币消失且余额为 1。第二次拾取途中打开今日计划，面板内仍为余额 1、地面 1，未提前到账。

关闭计划面板并暂停小镇动态后，点击仍在地面的第二枚金币，余额由 1 变为 2，地面币消失，并显示“拾到星球币啦 · +1 星球币”。家庭服务在端口 4180 重新启动加载服务端规则。
