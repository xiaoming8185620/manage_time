# 金币拾取与温室动物掉落

## 原因与修复

- 通用 button:active 位移会覆盖金币的定位 transform。金币新增专用按下样式，保持触点位置，热区扩大到 52×52 CSS 像素，绘制层级高于人物和动物。
- lifePaused 包含家庭服务保存状态，旧移动暂停逻辑清空到达计时器和拾取回调。独立样例在开始走路 120ms 后模拟 700ms 保存，修复前停步且余额不变；修复后保留目标，保存结束继续走到后只领取一次。
- 选中金币立即显示「正在拾取」，连点同一枚不重启路程。改道、打开面板、页面隐藏或切换场景清理拾取意图，金币仍保留。

## 第二幕玩法

鹦鹉每轮飞行结束、小蛇每轮探索结束时，各自按 30% 概率留下 1 星球币。三个落点均在中央可行走区域，随机选点，原处多个金币堆叠显示且逐枚领取。动物的活动时钟只在当前可见、未暂停、无面板及保存阻塞时推进。

服务器控制随机结果与落点；两个来源独立记录已判定轮次，成功失败都持久化。掉落时不发收入，拾取时一次性记入余额与每日手记。导出导入保留待领取金币、收入和轮次，旧存档默认空记录。
