# 云端书屋与奥莱手稿

目标：在主场景左下方加入可点击的沈石溪 NPC 与藏书架；打开阅读面板，阅读原创外星动物奥莱的故事，用星球币解锁留白章节。

边界：角色为游戏虚构演绎，奥莱为游戏原创而非沈石溪真实新作；真实书目与原创手稿清楚区分。沿用既有家庭端事务、版本冲突、重试机制及 localStorage，不改任务奖励或邮件设置。

实现：一个免费序章，六章依次解锁，每章 3 币、共 18 币；确认消费、余额不足不扣、重复解锁不扣、跨设备保存，导出导入保留记录并扣除已花费金额。每日手记记录解锁章节。素材使用内置 ImageGen，组件在 src，统一内容与价格放 shared。

验证：前后端扣币与幂等、乱序与余额不足、旧存档及导入、多设备版本冲突；浏览器检查场景入口、书目、章节留白、确认消费与阅读反馈、窄屏布局。消费测试使用临时数据目录，不修改体验账号余额或任务。

进度：实现、素材、验证均完成，服务已更新并保持运行。后续可按用户反馈调整书屋大小或继续扩充故事。

## 验证结果

- 25 项 Node 测试、35 项 Python 测试通过；普通构建与家庭版构建均通过。保护的 Sites 文件未改动。
- 新增扣币测试覆盖目录价格、重复操作编号、重复章节、余额不足、乱序与不存在章节、旧存档、无效进度、导入花费和数据库重开；版本冲突返回 409，不提前扣币。
- 浏览器独立测试居民：10 币打开确认，取消仍为 10；确认解锁第一章后为 7，正文可见，付币按钮消失；刷新后仍为 7，进度 2/7。每日手记可见章节名及“消耗 3 星球币”。
- 体验账号仅检查免费阅读、书屋位置与余额不足提示，未用其执行付币验收。测试站切换至 localhost:4186，避免同一浏览器下与 127.0.0.1:4180 共用同名 cookie；最终体验页登录与余额 1 币正常。
- 390×844 窄屏实测：页面宽 390、弹窗宽 372，无横向溢出；藏书架两列、章节四列换行，解锁区可滚动到达。已恢复默认浏览器尺寸。
- 书屋层级低于原植物照料热点，标签上移避免遮住“今天的一小步”；封面裁切改为顶部对齐，保留奥莱脸部。任务面板与系统动态控制同时约束书屋悬浮动画。
- 七章正文 2782 字，含免费相遇、营救邮羽鸟、失种误会、风暴计划、诚实认错、公平分水与开放式告别；每章附观察笔记和自由思考问题。
