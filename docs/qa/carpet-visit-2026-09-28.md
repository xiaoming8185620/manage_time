# 左下云层的飞毯来访

用户方向：飞行路线避免单一；飞毯放在左下云层，停下来问候再飞走，保持神秘。

- 复用已有 ImageGen 飞毯与云素材。飞毯从天空裁切层移到独立的下方云层，始终不拦截点击；问候层在植物之上、天气与 HUD 之下。
- 两段来访分别在活跃场景时间 28—54 秒、115—141 秒，沿不同三次贝塞尔曲线靠近与离开；其余访客时间不变，同屏最多两位。
- 停留锚点是场景 28%、94.6%；约 4.94 秒内做一次缓慢倾斜问候，显示“嘘……下次在云里见。”，随后平缓转向、缩远并淡入云雾。无需点击、无音效、无奖励或扣币。
- 位移、点头、转向、缩放、云雾透明度与文字渐显全部使用同一活跃时间轴；暂停、面板、后台恢复不跳过问候。
- 26 项 Node 测试通过，覆盖下方云层范围、首次提前出现、停留坐标、动作变化、离场淡出、不同来访路径、暂停冻结、并发访客上限。普通及家庭版构建通过。
- QA 页 `docs/qa/sky-life.html` 加入靠近/问候/离开/另一条路线按钮，并共用真实书屋组件和任务按钮位置；支持 `?time=39000` 固定核验时刻。浏览器无障碍树确认加载 39 秒核验页；此次浏览器点击与截图接口超时，未取得新的画面截图，不把数值测试当作完整视觉验收。

正式体验地址仍为 `http://127.0.0.1:4180/`；后端、账号与存档未改动。
