保存日期：2026-09-28。此版本为项目首次 Git 基线，包含当前完整代码、场景素材、设计约定与验收记录。

- 手绘 2.5D 悬浮小镇、主角移动与互动、小乖、植物分阶段成长和照料。
- 今日计划、现实任务记录、星球币奖励与建设、云端书屋和奥莱阅读。
- 杭州天气、飞船与采集机甲、飞毯旅人、继续前行离场的巡检员。

最近验证：31 项前端测试、39 项 Python 测试，以及标准前端和家庭版构建通过。浏览器已验证自然掉落、到达拾取、面板中断与暂停动态下拾取；详见相应 `docs/qa/` 记录。

版本库不包含孩子的 SQLite 存档、真实邮件配置、环境变量、依赖目录和构建产物。这些仍留在当前机器上。恢复此代码版本后，需要按 README 安装依赖并重新构建；邮件实际发送仍取决于本机 SMTP 配置。
