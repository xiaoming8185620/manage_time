# 星球悬浮小镇

面向 10—16 岁的时间管理游戏原型。手绘 2.5D 生态科幻悬浮平台，男孩和伙伴小乖一起，用真实行动获得星球币，建设自己的小镇。

## Python 家庭版

孩子只需输入名字，无需密码或登录名；家长点击“家长看记录”查看手记。通过家庭 Wi-Fi 在 iPad 或其他电脑上输入同一个名字，就能继续同一座小镇。每天保留任务与使用记录，每周日 20:00（北京时间）生成站内周报并按配置发送家长邮件。

```sh
python3 -m pip install -r requirements.txt
python3 app.py
```

先在服务器 Mac 打开 `http://localhost:4180` 输入孩子名字，再在其他设备访问 `http://旧Mac的局域网IP:4180`。Python 使用随代码提交的 `dist/family`，拉取后无需安装 Node 或重新构建。修改前端后执行 `npm run build:family`，并将更新后的网页一起提交。

配置、迁移、备份和统计口径见 [家庭版使用说明](docs/family-server.md)。SMTP 尚未配置时不会发信，页面会显示配置状态。`npm run dev` 继续保留原来的单机原型。

## 第一日可体验内容

- 点击木平台或使用方向键 / WASD 移动，点击小乖互动。
- 主角使用六帧交替迈步和摆臂，按距离匀速移动；途中可改方向，停下恢复空闲，暂停动态时停在当前位置。
- 主角空闲时自然呼吸、眨眼；进入小镇打一次招呼，点击主角或聚焦后按 Enter / 空格，会挥手并用短句回应。连点不会堆积动作，移动时收起气泡。
- 云层缓慢漂动，植物轻轻摇摆；小乖会闲逛、小跑跟随、低头闻闻，点击时跳跃或亲昵回应。
- 右上角风形按钮可暂停场景动态；打开面板、选择建设位置、页面隐藏或系统开启减少动态时自动暂停。
- 创建任务，填写具体小目标、分类、预计分钟和开始时间。
- 开始、暂停、继续、调整；离开页面后按真实时间恢复计时。计时记录经过时间，不推断真实专注时间。
- 回来记录完成、部分完成、实际用时和备注。
- 每个已完成任务领取一次 10 星球币，第一幕可花费 10 币建设猫爬架。小花圃已下架，历史存档与消费记录继续兼容。
- 新建或调整计划至少预计 10 分钟；回来记录时暂停计时，孩子填写实际用时。家庭版需累计运行至少 10 分钟，自报与服务器累计计时（四舍五入到分钟）相差不超过 5 分钟，才确认完成；预计偏差不影响奖励。主动暂停不计入，关闭页面仍计时，忘记暂停可保留说明并重开一段计时。
- 每天首次进入小镇自动获得 10 星球币（北京时间），与任务奖励分开记录；刷新、重复登录和多设备访问不重复领取，不要求连续到访。
- 新朋友先了解“安排现实小目标 → 离开屏幕行动 → 如实记录与回顾”，再由随进度变化的下一步提示带领体验；可跳过，也可在玩法说明中重新打开。
- 点击栏杆花草、盆栽、屋顶花丛，选择免费浇水或花 3 星球币照料；照料增加真实枝叶与花朵，依次达到舒展、繁茂、盛放，并永久保存。盛放后不再扣成长费用。
- 点击小乖、猫窝、小屋、太阳能板、工作台、灯和推进器互动，或用 2—4 星球币打理；非植物每个对象每天最多付币一次。“照料小镇”目录便于 iPad 点选。
- 扣币前显示价格与确认；余额不足、重复请求和旧版本操作不会额外扣费。家庭版在每日手记中记录照料对象、动作、费用和成长阶段。
- 预览位置后确认建造，取消不扣币；查看建筑、成就和简短回顾。
- 单机版用 localStorage 保存；家庭版由 Python 与 SQLite 保存并在设备间共享。两种模式均没有支付功能。

## 植物、任务提示与杭州天气

- 场景使用空盆与裸枝底图，每株植物根据保存的照料等级渲染四阶段独立素材。藤蔓、盆栽、树冠都从初生开始；付币成长后保留，免费浇水不跳级。
- “今天的一小步”默认收起为按钮。点击展开，进入面板时收起。手机的成长手记和照料入口放在场景下方。
- Python 的 `GET /api/weather` 固定读取浙江杭州（30.2741, 120.1551），不请求设备位置，不向天气服务发送孩子名字、任务或账号数据。
- 来源为 [Open-Meteo 当前天气](https://open-meteo.com/en/docs) 的气象模型估算，每 10 分钟缓存，前台页面每分钟检查更新，页面隐藏时暂停请求。天气时间和最近同步时间均按北京时间显示。
- 晴、多云、雨、雪、雾、雷雨及昼夜会改变场景光线与天气效果；雷雨不使用闪光。手动暂停、任务面板和系统减少动态都会约束动画。
- 请求失败保留最近天气并标注“上次”；超过 3 小时或从未成功时显示天气未连接，使用默认柔和晴景。天气不会增减星球币或改变植物等级。
- 天气缓存存于数据目录的 `weather-cache.json`，使用 Python 标准库，无额外依赖。Mac 需能访问 `api.open-meteo.com`。静态单机服务未连接 Python 接口时会如实显示天气未连接。
- 最新对照与测试证据见 `docs/qa/evolution-comparison.html` 和 `design-qa.md`。

角色互动修复（2026-09-28）：点击小乖直接免费互动，气泡期间可进入照料；暂停时仍显示文字回应。动态默认跟随系统，右上角可明确开启/暂停并在当前浏览器记住选择，玩法说明可恢复跟随系统。回归证据见 `docs/qa/interaction-regression-2026-09-28.md`。
# 云端访客

主场景动态现在包括飞船巡航、机甲采集、悬浮巡检员，以及偶尔出现的魔毯和流星。它们分批出场，并随小镇动态开关、任务面板和页面可见性暂停。效果不影响任务、星球币或成长存档。

实现验证见 [云端访客核验](docs/qa/sky-life-2026-09-28.md)，素材与完整提示词见 [访客素材](docs/qa/sky-life-assets.md)。

## 温室动物掉币与拾取

第二幕鹦鹉、小蛇完成一轮活动时，各自以 30% 概率留下 1 星球币，随机落在温室中央三处空地之一。落稳后点击，角色到达才收入钱包；金币未领取会保存，刷新或换设备后仍可拾取。点击会显示「正在拾取」，连点同一枚不会反复起步，短暂后台保存后继续行走；主动改道、开面板或离开当前场景取消拾取。服务端判定随机与防重复，收入进入每日手记。


## 第三幕：星核机械港

从云顶温室下方直接进入，底部楼梯返回温室，不设任务或星球币门槛。三幕共用今日计划、余额和家庭存档。原始选图位于 `docs/reference/workshop-approved-v1.png`。

- 悬浮补给舱、接驳台、装卸臂、升降平台、原地陪伴的机器狗小巡、清洁机器人点点、起降无人机星梭、地球全息仪和右侧智脑墨子均可互动。
- 免费互动随时可用；维护费用 2—4 星球币，确认后扣费，同一设备每天最多维护一次，不维护也不会损坏。
- 充电休息坞与星梭检修架各 10 星球币，一次建成永久保留，服务端校验费用和防重复，记录进入每日手记。
- 墨子根据今日计划给出规则式建议，不调用外部模型，不自动修改任务。
- 动态遵守全局开关、面板与页面隐藏状态；远近比例按脚点平滑变化。动效不会自动增加或扣除星球币。

家庭版仍使用 `python3 app.py --host 0.0.0.0 --port 4180` 启动，无额外 Python 依赖或数据库迁移。源码或素材变更后运行 `npm run build:family`，提交时应包含 `dist/family`。验收记录见根目录 `design-qa.md`；本地视觉对照页 `docs/qa/workshop.html` 使用独立临时状态，不写入孩子存档。

### 机械港成长

第三幕新增七组三阶段永久成长：墨子、小巡、全息仪、停机坪、清洁机器人、装配台、能源晶体。阶段费用 3／5／8 星球币，已有休息坞或检修架抵扣原有建设支出，满级不再收费。点场景物件或“建设”可查看下一阶段并确认安装。免费新本领包括机械臂回应、天体投影切换与放大、两条无人机巡航路线、选择清扫区域、制作收藏摆件、切换能源灯光。

成长进度、选项和收藏保存在 `workshopGrowth`，家庭版由 Python 校验并写入 SQLite；导出导入会核算成长消费，每日手记收录升级与互动。

### 悬浮补给港

环轨机车改为左侧云海补给港，旧轨道替换为通透步道和能源导管。补给舱从云海靠近，悬停扫描、卸货后继续向左前方离开；星梭将货箱送至前景升降台。每 70 秒一轮，基础表演免费，暂停和面板打开冻结进度，隐藏页面不补播。

接驳台、装卸臂、补给舱、升降平台另有四组三阶段成长，每组依次消耗 3／5／8 星球币；升级添加真实部件，成长永久保存。旧机车不再出现在维护目录，历史照料支出仍兼容。素材与布局见 `docs/reference/workshop-supply-v1.md`，验证见 `docs/qa/workshop-supply.md`。

## 三幕场景音乐

右上角音符按钮打开背景音乐设置。第一幕《云上的午后》使用拨弦与钟琴，第二幕《玻璃穹顶的呼吸》为空灵铺底与水滴音色，第三幕《星核的微光》使用柔和电子琶音。均为项目原创程序合成配乐，音轨在 `public/audio/`，随 `dist/family/audio/` 交付，不依赖外部音乐网站或新增 Python 库。

首次主动点击播放；切幕自动淡入淡出，打开任务等面板降低音量，离开页面暂停。音量记在当前浏览器，刷新后再次主动开启。音量、暂停与动画开关独立。素材说明见 `public/audio/README.md`，验证见 `docs/qa/scene-music.md`。
